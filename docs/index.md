# KernelExtensions 文档

**KernelExtensions** 是一个基于 **Pathfinder API** 的 Hacknet 模组，为扩展作者提供高度可配置的试炼、虚拟机攻击、飞机守护进程以及一系列自定义动作。

> 当前文档对应 **0.6 版本**（`main` 分支）。0.7 开发版文档见 `dev` 分支的 `docs/`。
