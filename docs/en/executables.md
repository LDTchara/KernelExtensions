# Executables

KernelExtensions currently provides one custom executable: **CustomTrial**.

- Purpose: runs multi‑phase trials driven by XML configuration files.
- Activation: uses a Flag starting with `CustomTrial_` to specify the configuration (e.g. `CustomTrial_MyTrial`).
- Program file: `CustomTrial.exe`, which must be present in the player's `bin/` folder.

For detailed usage, configuration, and available effects, see the **[Custom Trial System](./custom-trial.md)** page.
