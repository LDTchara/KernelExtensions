# 可执行程序

目前 KernelExtensions 提供了一个自定义的可执行程序：**CustomTrial**。

- 作用：运行由 XML 配置文件驱动的多阶段试炼。
- 激活方式：通过 `CustomTrial_` 开头的 Flag 指定要加载的配置（例如 `CustomTrial_MyTrial`）。
- 程序文件：`CustomTrial.exe`，需放置在玩家 `bin/` 文件夹中。

详细用法、配置说明和可用特效请参阅 **[自定义试炼系统](./../systems/custom-trial.md)** 页面。
