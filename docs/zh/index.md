# 🔧 KernelExtensions Wiki（简体中文）

**KernelExtensions** 是一个基于 **Pathfinder API** 的 Hacknet 模组，为扩展作者提供高度可配置的试炼、虚拟机攻击、飞机守护进程以及一系列自定义动作。

> 本文档对应 **KernelExtensions 0.6**。

## ⚙️ 前置要求

- **Hacknet** + DLC **Labyrinths**
- **Pathfinder** 5.3.4+

> **注意**：本模组必须作为扩展的一部分运行，不支持全局插件模式。
